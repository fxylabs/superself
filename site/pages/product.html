AI 에이전트가 업무를 실행하는 플랫폼

Superself는 고객의 AI 에이전트가 API로 실제 업무를 실행할 수 있게 하는 플랫폼입니다. self CLI는 완전한 오픈소스로 단독으로도 동작하며, 업무 API는 그 CLI로 접속하는 클라우드 유료 서비스입니다. 에이전트는 이메일을 보내고, 이메일 링크가 열리는 랜딩 페이지를 배포하고, 결과와 비용을 확인할 수 있습니다.

사람은 하나의 계정에서 결제수단, 하나의 선불 지갑, 지출 한도와 권한을 정합니다. 에이전트는 self CLI를 시작점으로 사용해 허용된 API를 호출합니다. 각 API는 확인이 필요한 작업을 사람이 처리할 수 있는 웹 화면과 연결된 미니앱으로 제공됩니다. 이메일 전송과 랜딩+분석이 첫 미니앱입니다.

알림톡은 9월에 추가하고, 더 많은 업무 API는 이후 로드맵에서 정합니다.

이메일 API

에이전트는 self email send로 수신자, 제목, 본문 또는 템플릿을 전달합니다. 발신 도메인을 확인한 뒤 사용할 수 있으며, 발송 목적도 함께 선언합니다.

발송 전에 콘텐츠와 링크를 검증합니다. 검증을 통과하지 못한 요청은 전송하지 않습니다. 전송이 수락된 수신자만 사용량으로 계산하며, 검증 거부·전송 실패·수신 거부 대상은 차감하지 않습니다.

이메일은 수신자 1명당 ₩1입니다. USD 계정은 수신자 1명당 $0.001입니다. 무료 사용량은 이메일 하루 100건, 매월 3,000건이며 발신 도메인 확인이 필요합니다. 무료 티어 발송은 고정 템플릿만 사용할 수 있습니다.

알림톡 API

알림톡 API는 9월 출시 범위입니다. 무료 티어는 제공하지 않으며, 가격과 온보딩 크레딧 제공 여부는 9월 출시 전에 확정합니다.

Landing Kit

Landing Kit은 이메일 링크를 눌렀을 때 열리는 페이지를 호스팅하는 미니앱입니다. 광고 링크에도 사용할 수 있고, 페이지뷰, 클릭, 외부 링크, 폼 제출 등의 분석 기능이 함께 제공됩니다. 에이전트는 정적 HTML을 배포하고 사람은 웹 화면에서 사이트와 분석을 확인합니다.

당사 서브도메인에 호스팅 랜딩 사이트 1개를 무료로 제공하며, 무료 티어의 분석 데이터는 30일간 보존합니다.

하나의 운영 레일

가입 후 카드 등록과 지갑 충전을 한 번 설정합니다. 이메일, 알림톡, Landing Kit은 같은 계정과 지갑을 사용합니다.

각 계정은 가입 시 KRW 또는 USD 중 하나를 기본 통화로 선택합니다. 통화는 혼합하거나 환전하지 않습니다. 지갑 잔액, 사용 내역, 자동 충전 상태는 self wallet과 사람용 웹 화면에서 확인할 수 있습니다.

자동 충전은 KRW 계정에서 빌링키로 설정할 수 있습니다. 기준 잔액, 충전 금액, 월 한도를 직접 정해야 합니다. USD 계정은 수동 충전 방식이며 잔액이 낮아지면 이메일과 CLI 응답으로 안내합니다. 무료 사용량 이후 유료 이메일은 KRW 계정은 ₩10,000 이상, USD 계정은 $10 이상 충전한 지갑 잔액으로만 사용할 수 있습니다.

사람과 에이전트의 역할

사람은 다음을 결정합니다.

  • 카드 등록과 지갑 충전
  • 자동 충전 기준과 월 한도
  • 발신 도메인과 에이전트 권한
  • 자격증명 폐기와 계정 종료

에이전트는 승인된 범위에서 다음을 수행합니다.

  • self email send, self email stats
  • self landing deploy, self landing stats
  • self wallet를 통한 잔액·사용 내역 조회

에이전트에는 장기 API 키를 전달하지 않습니다. 기기 코드 로그인으로 발급된 짧은 수명의 자격증명에 작업 범위를 붙이며, 사람은 이를 언제든 폐기할 수 있습니다. 에이전트가 지갑을 충전하거나 관리자 작업을 실행하는 권한은 제공하지 않습니다.

전송 전에 멈추는 안전장치

모든 발송 콘텐츠와 랜딩 HTML은 검증 대상입니다.

  • 검증이 통과하지 않으면 전송하지 않는 fail-closed 검증
  • 계정별 이메일 전송 환경 분리
  • 반송과 불만이 기준을 넘을 때 자동 일시정지
  • 계정별 지출 한도와 사용량 제한
  • 에이전트별 짧은 수명과 범위 제한 자격증명

발송이 실패하면 지갑을 차감하지 않습니다. 잔액이 부족하면 전송 전에 요청을 거절하거나, 설정된 충전 절차가 끝난 뒤 재시도할 수 있는 응답을 돌려줍니다.

시작 순서

  1. Superself 계정을 만들고 KRW 또는 USD를 선택합니다.
  2. 카드를 등록하고 지갑을 충전합니다.
  3. 이메일을 사용한다면 발신 도메인을 확인합니다.
  4. self login으로 에이전트 기기를 승인합니다.
  5. 에이전트가 CLI에서 발송 또는 랜딩 배포를 실행합니다.
  6. 사람과 에이전트가 잔액, 사용량, 통계를 확인합니다.

사람이 방향과 비용을 정하고, 에이전트가 승인된 업무를 실행합니다. 서비스 범위와 요금은 공개 페이지와 결제 화면에 표시한 출시 버전에 따릅니다.
