가격

Superself는 고객의 AI 에이전트가 API로 업무를 실행하도록 하는 플랫폼입니다. self CLI는 완전한 오픈소스이며, 업무 API는 클라우드 유료 서비스입니다. 사람은 하나의 계정에서 하나의 선불 지갑을 충전하고, 에이전트는 self CLI로 허용된 API를 사용합니다. 월정액이 아니라 선불 지갑과 사용량으로 과금합니다.

표시 가격은 부가가치세 별도이며, 결제 화면에서 카드 청구액을 함께 표시합니다. 예: ₩10,000 충전 (부가세 별도, 카드 청구액 ₩11,000). USD 결제 총액에는 결제사업자가 처리하는 적용 가능한 세금이 포함될 수 있습니다.

지갑

  • 가입 시 KRW 또는 USD 중 하나를 기본 통화로 선택합니다.
  • 한 계정에서 통화를 섞거나 환전하지 않습니다.
  • 카드는 파일에 등록하고, 충전과 결제 내역은 사람용 웹 화면에서 확인합니다.
  • 에이전트는 지갑을 충전할 수 없습니다.
  • 잔액보다 큰 유료 요청은 전송 전에 거절합니다.

충전 팩

KRW

₩10,000 / ₩50,000 / ₩100,000 / ₩300,000

KRW 충전의 1회 금액 범위는 ₩10,000–₩1,000,000이며, 최소 충전액은 ₩10,000입니다.

USD

$10 / $50 / $100 / $300

USD 충전은 1회 $10–$700 범위이며, 최소 충전액은 $10입니다. USD 계정은 수동으로 충전하며 잔액이 낮아지면 이메일과 CLI 응답으로 안내합니다.

이메일 API

항목요금
KRW 계정 이메일수신자 1명당 ₩1
USD 계정 이메일수신자 1명당 $0.001

요금은 발송 요청의 수신자 수가 아니라 실제 전송이 수락한 수신자 수를 기준으로 합니다. 검증 거부, 전송 실패, 수신 거부 대상은 차감하지 않습니다.

무료 이메일

  • 하루 100건
  • 월 3,000건
  • 발신 도메인 확인 후 사용
  • 무료 티어 발송은 고정 템플릿만 사용
  • 도메인 확인 전에는 계정 소유자가 확인한 주소로만 데모 발송

무료 사용량은 Asia/Seoul 기준으로 날짜와 월이 바뀔 때 다시 계산됩니다. 무료 사용량을 넘긴 요청은 남은 수량을 포함해 거절 결과를 반환합니다.

무료 사용량 이후 유료 이메일은 KRW 계정은 ₩10,000 이상, USD 계정은 $10 이상 충전한 지갑 잔액으로만 사용할 수 있습니다.

Landing Kit

당사 서브도메인에 호스팅 랜딩 사이트 1개를 무료로 제공하며, 무료 티어의 분석 데이터는 30일간 보존합니다. Landing Kit은 정적 HTML을 호스팅하고 분석 이벤트를 제공합니다. 유료 계정의 사이트 수와 유료 기능은 결제 화면에 표시합니다.

랜딩 페이지의 호스팅 비용은 현재 ₩0입니다. 커스텀 도메인은 현재 제공하지 않습니다.

알림톡 API

알림톡은 9월 출시 예정이며 무료 티어는 없습니다. 가격과 온보딩 크레딧 제공 여부는 9월 출시 전에 확정합니다.

알림톡의 건당 요금, 크레딧의 적용 조건과 유효기간은 출시 전 확정합니다.

자동 충전

KRW 계정은 카드 빌링키로 자동 충전을 설정할 수 있습니다. 자동 충전을 켤 때 다음 세 가지를 모두 정합니다.

  • 충전 시작 기준 잔액
  • 한 번에 충전할 금액
  • 월별 최대 충전 한도

계정이 일시정지되었거나 서비스를 사용할 수 없는 상태에서는 자동 충전을 실행하지 않습니다. USD 계정은 수동 충전 방식입니다.

환불

사용하지 않은 선불 잔액은 계정 종료 시 환불 대상입니다. 무료·프로모션 크레딧과 이미 사용한 금액은 환불하지 않습니다. 원 결제수단, 여러 번의 충전, PG 처리 가능 여부에 따른 환불 방식은 환불규정에 따릅니다.
